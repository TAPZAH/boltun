# Как помочь проекту

Спасибо за интерес к Boltun!

## Сообщения об ошибках

1. Проверьте, нет ли уже похожего issue.
2. Приложите:
   - версию Android и модель устройства;
   - что делали и что ожидали;
   - в каком приложении выделялся текст;
   - результат кнопки «Проверить захват выделения» (источник: cache/node/copy/clipboard);
   - логи (`adb logcat`) при падении.

## Предложения

Опишите задачу и желаемое поведение. Для UI-изменений приветствуются скриншоты/наброски.

## Pull request

1. Форкните репозиторий и создайте ветку от `main`.
2. Соблюдайте стиль кода (Kotlin, без лишних комментариев).
3. Убедитесь, что проект собирается:
   ```bash
   ./gradlew assembleDebug
   ```
4. В описании PR укажите, что и зачем изменено.

## Лицензия

Отправляя изменения, вы соглашаетесь с тем, что они распространяются под GPL-3.0 (см. [LICENSE](LICENSE)).
