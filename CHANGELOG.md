# Changelog

Все значимые изменения проекта Boltun.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] - 2026-09-26

### Added
- Плавающая кнопка поверх других приложений и озвучка выделенного текста (одиночный тап).
- Захват выделения через AccessibilityService: кэш события, обход узлов, `ACTION_COPY`, чтение буфера с временным фокусом.
- Меню по двойному тапу: счётчик предложений, навигация по предложениям, старт/пауза, стоп, скорость.
- Продолжение с места (`Continue where left off`) и переигровка с начала.
- Скорости воспроизведения: 0.75, 0.90, 1.00, 1.10, 1.25, 1.50, 2.00.
- Способы входа: `PROCESS_TEXT` («Озвучить» в меню выделения) и `ACTION_SEND` («Поделиться»).
- Выбор движка синтеза: системный по умолчанию или конкретный установленный.
- Автозапуск после перезагрузки, уведомление со «Стоп», отключение оптимизации батареи.
- Локализация: русский, украинский, английский, испанский.
- Диагностика захвата выделения (источник и длина).

### Fixed
- Перемотка: уникальные `utteranceId`, игнорирование устаревших колбэков движка.
- Счётчик предложений обновляется по ходу чтения.
- Смена движка синтеза подхватывается и пересоздаётся.
- «Продолжить с места»: корректное сохранение позиции при паузе/стопе.
